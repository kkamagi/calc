# calc

추림생활 계산기. 공식 산정 방식 그대로 계산하는 정적 웹 계산기 모음입니다.

**https://kkamagi.github.io/calc/**

## 왜 만들었나

네이버 블로그 본문에는 JavaScript가 들어가지 않습니다(스마트에디터가 `script`·`iframe`·`embed`를
강제로 제거합니다 — [smarteditor2#226](https://github.com/naver/smarteditor2/issues/226)).
그래서 "계산기"를 제목에 건 글이 정작 계산기 없이 설명만 담게 되고, 계산기를 찾아온 방문자는
바로 이탈합니다. 이 저장소는 그 글들이 실제로 가리킬 수 있는 계산기를 둡니다.

## 퇴직금 계산기

고용노동부 퇴직금 계산기(`retire_cal.js`)의 산정 로직을 그대로 구현했습니다.

- 산정기간을 월 경계로 분할 (퇴사일이 1일이면 3구간, 아니면 4구간)
- 5월 29일(평년)·30일·31일 퇴사는 2월을 건너뛰기 위해 3구간으로 강제
- 산정기간 시작일이 해당 월에 없으면 말일 기준으로 보정
- 상여금·연차수당은 연간액의 3/12만 가산
- 미산입기간은 분모(일수)와 분자(임금)에서 함께 차감
- 근무제외기간은 재직일수에서만 차감
- 1일 평균임금은 소수 셋째자리 **올림**, 퇴직금은 원 단위 반올림
- 평균임금이 1일 통상임금보다 적으면 통상임금으로 대체

공식 예제(입사 2014-10-02 / 퇴사 2017-09-16 / 3개월 임금 7,080,000원 / 상여금 4,000,000원 /
연차수당 300,000원)로 검증했습니다 — 총일수 92일, 재직일수 1,080일, 1일 평균임금 88,641.31원,
퇴직금 7,868,434원으로 공식 계산기와 일치합니다.

공식 계산기에 없는 것 두 가지를 더했습니다. 월급이 일정한 경우 기간별 입력 없이
월 급여 하나로 계산하는 간편 모드, 그리고 상여금·미산입기간을 비워 두었을 때
"넣지 않으면 실제보다 적게 나온다"고 알리는 경고입니다.

## 실업급여 계산기

고용보험법·시행령·시행규칙 원문(국가법령정보센터 공개 API)을 근거로 구현했습니다.

- 기초일액 = 이직 전 3개월 임금총액 ÷ 총일수(근기법 제2조제1항제6호). 산정기간 분할은 퇴직금 계산기와 같은 규칙
- 통상임금이 더 크면 통상임금을 기초일액으로 대체(법 제45조제2항)
- 기초일액 상한 11만 3,500원(영 제68조제1항, 2026-01-01 시행) → 구직급여 상한 68,100원
- 최저기초일액 = 1일 소정근로시간 × 이직일 당시 최저임금(법 제45조제4항).
  임금이 여기에 못 미치면 최저기초일액의 80%(제46조제1항제2호), 60%가 하한에 못 미치면 하한액(제46조제2항)
- **상·하한액은 이직일 기준으로 갈립니다** — 시행령 부칙(대통령령 제35934호) 제4조가
  "이 영 시행 전에 이직한 사람"에게 종전 규정을 적용하도록 정합니다. 신청일이 아닙니다
- 소정급여일수는 별표 1 원문 그대로. 장애인은 50세 이상으로 보아 적용(별표 1 비고)
- 1일 소정근로시간을 모르면 주 소정근로시간으로 산정(시행규칙 제91조의2제1항제2호)

**피보험기간 경계는 일수가 아니라 날짜로 잽니다.** 365×N 으로 재면 윤년이 낀 구간에서
하루 어긋나 30일분이 잘못 나옵니다(입사 2016-08-22·이직 2026-08-20 이면 240일인데 270일로 나옴).
초일을 산입한 민법식 기간으로 판정합니다.

고용보험 모의계산(work24) 서버 응답으로 검증했습니다 — 2026년 상한 68,100원·하한 66,048원,
2025년 66,000원·64,192원, 상한이 기초일액 단계에 걸리는 것(113,499원 → 68,099원),
1일 소정근로시간 4시간이면 하한만 33,024원으로 줄고 상한은 그대로인 것,
피보험기간 경계(2023-08-21 입사 = 3년 이상, 2023-08-22 = 3년 미만),
연령 경계(생일 당일이면 50세 이상)까지 일치합니다. 페이지를 열면 콘솔에 검증 23건이 찍힙니다.

공식 계산기에 없는 것을 더했습니다. **근속 3·5·10년 경계나 만 50세 생일이 이직일과 90일 안쪽이면
며칠 차이로 30일분이 달라진다는 것을 금액까지 짚어 줍니다.** 하한액에 걸린 경우에는
"임금이 얼마든 하루 금액은 같다"는 사실과 그 경계 금액을 함께 보여 줍니다.

## 원칙

- 외부 의존성 없음. HTML 파일 하나에 CSS·JS가 전부 들어 있습니다.
- 입력값은 브라우저 밖으로 나가지 않습니다. 전송도 저장도 하지 않습니다.
- 광고 없음, 로그인 없음, 추적 없음.
- 계산 결과는 참고용이며 법적 효력이 없습니다.
